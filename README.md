# MH Design — Modern Home

Сайт дизайн-студии интерьеров «Modern Home»: светлая тема, жидкое стекло, прелоадер,
полноэкранные скролл-презентации этапов и «Почему мы». Без внешних библиотек — только Google Fonts.

**Сайт:** https://wai7e.github.io/mh-interio/

## Файлы

| Файл | Зачем |
|---|---|
| `src/mh-site.html` | **Исходник.** Все правки делаются только здесь. |
| `index.html` | Полная страница для GitHub Pages. Генерируется — вручную не редактировать. |
| `tilda/mh-tilda-block.html` | Блок для Tilda. Генерируется — вручную не редактировать. |
| `build.mjs` | Сборка обеих версий из исходника. |

## Правки

```bash
node build.mjs
```

После изменения `src/mh-site.html` запустите сборку и закоммитьте все три файла.

## Tilda

1. Добавьте на страницу один блок «Другое → HTML-код» (T123).
2. Вставьте в него целиком содержимое [`tilda/mh-tilda-block.html`](tilda/mh-tilda-block.html)
   (на GitHub: открыть файл → кнопка **Raw** → выделить всё → скопировать).
3. Ширина блока — 100%, отступы сверху и снизу — 0. Остальные блоки удалите.
4. Опубликуйте страницу: в редакторе и предпросмотре Tilda показывает код текстом,
   сайт оживает только на опубликованной странице.

## GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
