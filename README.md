# MH Design — Modern Home

Сайт дизайн-студии интерьеров «Modern Home»: светлая тема, жидкое стекло, прелоадер,
полноэкранные скролл-презентации этапов и «Почему мы». Без внешних библиотек — только Google Fonts.

**Сайт:** https://wai7e.github.io/mh-interio/

## Файлы

| Файл | Зачем |
|---|---|
| `mh-design-tilda-block.html` | Блок для Tilda. **Источник правды** — все правки делаются здесь. |
| `index.html` | Полная страница для GitHub Pages. Генерируется из блока, вручную не редактировать. |
| `build.mjs` | Сборка `index.html` из блока. |

## Правки

```bash
node build.mjs
```

После изменения `mh-design-tilda-block.html` запустите сборку и закоммитьте оба файла.

## Tilda

1. Добавьте на страницу один блок «HTML-код» (T123).
2. Вставьте в него целиком содержимое `mh-design-tilda-block.html`.
3. Ширина блока — 100%, отступы сверху и снизу — 0. Остальные блоки удалите.

## GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
Через минуту сайт откроется по ссылке выше.
